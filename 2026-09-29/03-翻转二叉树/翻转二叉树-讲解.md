# 226. 翻转二叉树 · 讲解

![来源](https://img.shields.io/badge/详解来源-Krahets-009688?style=flat-square) ![方法](https://img.shields.io/badge/方法-递归-blue?style=flat-square) ![复杂度](https://img.shields.io/badge/时间-O(N)-yellow?style=flat-square)

> [!info] 导航
> 📄 题目：[[翻转二叉树-题目]] ｜ 🔗 [Krahets 原题解](https://leetcode.cn/problems/invert-binary-tree/solutions/2361621/226-fan-zhuan-er-cha-shu-fen-zhi-qing-xi-tqlf/)（本篇按其思路整理扩写）

> [!abstract] TL;DR
> 翻转 = 每个节点**交换左右孩子**。递归三步：空返回；两个孩子交给递归去翻（归纳法：**假设它已经会翻任何树**）；换回来；返回自己。最大的坑：**先改 `root.left` 会弄丢原来的左子树**——要先暂存（或用 Python 平行赋值，右边先全部算完再一起赋值）。

> [!info] 术语小卡片（后面看不懂的词，回来查这里）
> - **镜像 / 翻转**：每个节点的左右孩子互换，整棵树左右对调。
> - **暂存（tmp）**：改之前先把旧值抄一份到临时变量，防止改完找不回。
> - **平行赋值**：Python 的 `a, b = b, a`。右边先打包成一个元组，再一次性解包给左边。
> - **原地修改**：直接改树上现成的指针（root.left / root.right），不新建一棵树。

## 🧱 一、把定义翻译成递归三步

题面定义（Krahets 版）：“任意节点 root，左 / 右子节点 left, right；镜像里对应节点的左 / 右子节点是 right, left。”

用人话说：**换孩子**。套上 104 题学的递归心法（“假设子问题已经解决”），三步就出来了：

1. **终止**：节点为空 → 返回 `None`（空树翻完还是空树）；
2. **递推**：左孩子 = 已翻转的（原来的右子树）；右孩子 = 已翻转的（原来的左子树）；
3. **返回**：自己（题目要求返回根节点）。

> [!tip] 归纳法再次登场
> 写 `invertTree(root.right)` 时，**假设它返回的右子树已经翻好了**——不用管它内部怎么跑。你只负责自己这一层：接住翻好的子树，挂到对面的位置上。

## 🚧 二、最大的坑：先改 `root.left`，就再也找不到原来的左子树

详解里的 Q&A 值得单独放大：**为什么要 tmp 暂存？**

看错误写法（我实测过，这是真实输出）：

```python
def invert_wrong(root):
    if not root: return None
    root.left = invert_wrong(root.right)   # ← 这行执行完，root.left 已经不是原来的孩子了！
    root.right = invert_wrong(root.left)   # ❌ 这里拿到的"左孩子"其实是刚换过来的右子树
    return root
```

用例 2 `[2,1,3]` 跑：第一行让 `2.left` 指向翻好的 3；第二行去"翻转左孩子"——翻的是 **3**（又翻回原样），最后 `2` 的两个孩子**都指向同一个节点 3**，原来的 `1` 彻底丢失。输出 `[2,3,3]` ❌。

用例 1 更惨：`[4,7,7,9,9,9,9]`——同一个子树被接到好几个位置（对象共享），整棵树面目全非。

> [!warning] 口诀：换孩子，先抄后改
> 要覆盖一个指针之前，它身上的旧值如果还有用，**先抄到临时变量 tmp 里**。

## 🐍 三、Python 特权：平行赋值，tmp 都不用写

```python
root.left, root.right = self.invertTree(root.right), self.invertTree(root.left)
```

为什么这行**不需要暂存**也不会出错？平行赋值的规则：

1. **先**把等号右边**全部求值完**（两次递归调用都跑完，结果打包成元组）；
2. **再**一次性从左到右赋给等号左边。

所以 `root.left` 被覆盖之前，右边那个"翻转后的原左子树”早就备好了——`a, b = b, a` 能一行交换两个变量，就是这个原理。

## 📜 四、完整代码（逐行注释版）

**版本一：tmp 暂存（详解原版，任何语言通用）**

```python
class Solution:
    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        if not root:                  # 刹车：空树，翻完还是空
            return None
        tmp = root.left               # 暂存左孩子（先抄后改！）
        root.left = self.invertTree(root.right)   # 左 = 翻转后的原右子树
        root.right = self.invertTree(tmp)         # 右 = 翻转后的原左子树
        return root                   # 题目要求返回根节点
```

**版本二：平行赋值（Python 特权，更短）**

```python
class Solution:
    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        if not root:
            return None
        # 右边两次递归先全部算完、打包，再一起赋值——天然避开了覆盖问题
        root.left, root.right = self.invertTree(root.right), self.invertTree(root.left)
        return root
```

> [!note] `if not root` 和 `is None`
> 这里 `not root` 与 `root is None` 等价（空树时 root 是 None）。上一题我们用 `is None`，这题跟详解用 `not root`——两种都地道，统一用哪种都行。

## 🔍 五、手动模拟：示例 2 `[2,1,3]`

```text
    2
   / \
  1   3
```

| 步 | 调用 | 发生了什么 |
| --- | --- | --- |
| 1 | `invert(2)` | 非空；`tmp = 1`（先抄下左孩子） |
| 2 | `invert(3)`（进原右子树） | 3 是叶子：左右都是空 → 返回 3 |
| 3 | 回到 `invert(2)` | `2.left = 3`（挂上翻好的原右子树） |
| 4 | `invert(1)` | 1 是叶子 → 返回 1 |
| 5 | 回到 `invert(2)` | `2.right = 1`（挂上翻好的原左子树），返回 2 |

结果：`2` 的左 3 右 1，序列化 `[2,3,1]` ✅

> [!success] 实测结果
> 正确两版（tmp / 平行赋值）在例 1、例 2、空树上全部通过；上一轮的自测树也翻对了（`[1,3,2,null,null,4]`，`4` 从 `2` 的右边换到了左边）。而"忘暂存"版在所有非空用例上全错。

## 📊 六、复杂度分析

- **时间 O(N)**：每个节点被访问一次、交换一次孩子，N 个节点 N 次操作；
- **空间 O(N)**：递归栈的层数 = 树高；最坏退化成链表时 h = N。

## 🧭 要点回顾

> [!summary] 一句口诀 + 两个细节
> **口诀：换孩子，先抄后改。**
> 1. 覆盖 `root.left` 之前，旧左孩子还有用——先 `tmp` 暂存（或用平行赋值让右边先算完）；
> 2. 归纳法照旧：你只管"换我的两个孩子"，子树内部交给递归，**假设它已经会翻了**。

**模板价值**：这是"**自底向上、原地修改**"型递归的代表——返回值不是答案，而是**改造后的子树根**。104 题练"返回数值"，本题练"返回结构"，合起来树形递归的两大流派就齐了。
