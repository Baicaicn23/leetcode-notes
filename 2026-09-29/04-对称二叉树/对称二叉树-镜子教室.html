一棵树，照镜子

上一题我们把树翻转了，这一题只问一句：这棵树照镜子之后，还和原来一样吗？ 这个页面不讲大道理——拖动下面的"镜子实验室"，亲眼看"交叉配对"怎么一步步走完全树。

1镜子实验室：亲眼看交叉配对

第 1 / 1 步

2check 函数的三连问（顺序不能换！）

第一问：两个都空？

通过。两边都走到了尽头，这一支从头对称到底——它是对称的"最底层证据"。

第二问：只有一边空？

拦下。一个有孩子、一个没有，形状都不同了，必定不对称。

第三问：值不一样？

拦下。形状对了，镜子里的数字也得一样才行。

顺序反了会怎样？

先问"单空"的话，(空, 空) 这对模范组合会被误判成不对称。实测 [1,2,2] 会错答 false——所以必须先双空！

3代码是怎么长出来的

class Solution:
    def isSymmetric(self, root) -> bool:
        def check(left, right) -> bool:
            if left is None and right is None:  # 一问：双空
                return True
            if left is None or right is None:   # 二问：单空
                return False
            if left.val != right.val:            # 三问：值不同
                return False
            return check(left.left, right.right) and check(left.right, right.left)
        return check(root, root)   # 起手式：树和自己的镜像比
  • 起手式 check(root, root)：派两个"影子分身"都从根出发——一个按原样走左，一个按镜像走右。不用真的翻转，影子替你比。
  • 交叉递归：check(左.左, 右.右) 是外侧配外侧；check(左.右, 右.左) 是内侧配内侧。"交叉"二字就在参数里。
  • and 会短路：前一对已经 False，后一对根本不跑——一票否决，立刻返回，一步都不浪费。
  • 复杂度：时间 O(n)（每节点查一次）；空间 O(h)（递归栈 = 树高）。
