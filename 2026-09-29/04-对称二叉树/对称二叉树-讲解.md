# 101. 对称二叉树 · 讲解

![方法](https://img.shields.io/badge/方法-递归+队列迭代-blue?style=flat-square) ![复杂度](https://img.shields.io/badge/时间-O(N)-yellow?style=flat-square)

> [!info] 导航
> 📄 题目：[[对称二叉树-题目]] ｜ 📝 题解代码由用户提供，本篇讲解为原创扩写

> [!abstract] TL;DR
> 判断对称 = 判断"**左子树和右子树互为镜像**"。写一个能比较**任意两棵树**是否互为镜像的函数 `check(l, r)`，起手式是 `check(root, root)`（让树和自己的镜像比）。`check` 内部是**三连问**：双空 ✅ → 单空 ❌ → 值不同 ❌，然后**交叉递归** `check(l.left, r.right)` 和 `check(l.right, r.left)`。最大的坑：**三连问的顺序不能换**。

> [!info] 术语小卡片（后面看不懂的词，回来查这里）
> - **交叉配对**：镜像的配对规则——左树的**左**孩子 ↔ 右树的**右**孩子；左树的**右**孩子 ↔ 右树的**左**孩子。
> - **短路求值**：`A and B` 里若 `A` 已经是 False，`B` 根本不会执行——一票否决，立刻返回。
> - **队列（queue）**："先进先出"的排队本。`deque` 是 Python 的双端队列，从左边取、右边存。
> - **递归基**：让递归停下来的最简单情况，本题是"两个都空"。

## 🧱 一、从"照镜子"到函数签名

[[翻转二叉树-讲解|上一题]]是把镜子里的样子**真的改造**出来；这道题只**判断**：翻转后和自己一样吗？

关键转化一步到位：**树对称 ⇔ 左子树和右子树互为镜像**。于是需要一个工具——能判断"**任意两棵树** `l` 和 `r` 是否互为镜像"的函数：

```python
def check(left, right) -> bool: ...
```

> [!tip] 起手式 `check(root, root)` 的巧思
> 用**两个影子分身**从根出发：分身甲按树的**原样**往左走，分身乙按**镜像**的走法往右走——任何时刻两人的位置就应该是对称的。所以不用真的翻转，`check(root, root)` 一句起手，分身们会替你走完全树。

## 🚧 二、三连问：顺序不能换

`check(l, r)` 每次进门先做三件事：

| 顺序 | 问题 | 回答 | 为什么 |
| --- | --- | --- | --- |
| 1 | 两个**都**空？ | `True` | 都走到尽头，这一支对称到底 ✅ |
| 2 | **只有一方**空？ | `False` | 一个有一个没有，形状就不对称 |
| 3 | 值不相等？ | `False` | 形状对，数字不对也不行 |

> [!bug] 问 1 和问 2 颠倒，全盘皆输
> 如果先问"有一方是空吗？→ False"，那么 `(None, None)` 这对**最合法的组合**也会被拦下误判成 False。我用 `[1,2,2]`（左右子树都是叶子 2）实测过：顺序颠倒版输出 **False**，正确答案是 **True**。必须**先双空、再单空**。

## 🧵 三、交叉递归 + `and` 短路

```python
return check(left.left, right.right) and check(left.right, right.left)
```

这一行浓缩了全部镜像规则：

- `check(left.left, right.right)`：外侧配外侧（左.左 ↔ 右.右）；
- `check(left.right, right.left)`：内侧配内侧（左.右 ↔ 右.左）——**交叉**就在这里。

两个都 `True` 才对称，所以用 `and` 连接。`and` 自带**短路**：前一个已经是 `False`，后一个根本不会执行——发现一处不对称，立即投降返回，不浪费一步。

## 📜 四、完整代码（逐行注释版）

```python
class Solution:
    def isSymmetric(self, root: TreeNode | None) -> bool:
        def check(left: TreeNode | None, right: TreeNode | None) -> bool:
            if left is None and right is None:   # 问 1：双空 → 这一支对称到底
                return True
            if left is None or right is None:    # 问 2：单空 → 形状不对
                return False
            if left.val != right.val:            # 问 3：形状对但值不同
                return False

            # 交叉递归：外侧配外侧，内侧配内侧；and 短路，一票否决
            return check(left.left, right.right) and check(left.right, right.left)

        return check(root, root)   # 起手式：树和自己的镜像比
```

## 🔍 五、手动模拟

**例 1 `[1,2,2,3,4,4,3]`：全员通过**

| 调用 | 比较 | 结果 |
| --- | --- | --- |
| `check(1, 1)` | 值相等 | 递归交叉对 |
| `check(2, 2)` | 值相等 | 递归交叉对 |
| `check(3, 3)` | 值相等 → 两个孩子双空 | `True` |
| `check(4, 4)` | 同上 | `True` |
| `check(2, 2)`（右半） | 同左半 | `True` |

全链 `True` ✅

**例 2 `[1,2,2,null,3,null,3]`：`and` 短路立功**

| 调用 | 比较 | 结果 |
| --- | --- | --- |
| `check(1, 1)` | 值相等 | 递归交叉对 |
| `check(2, 2)` | 值相等 | 递归交叉对 |
| `check(2.left=None, 2.right=3)` | 单空 ❌ | `False` |
| `check(2.right, 2.left)` | **短路，根本没跑** | — |

`False` 一路传回 → `false` ✅ 左 2 的 3 挂右、右 2 的镜像位置（左）却是空——正是题意阶段发现的那个错。

## 🎯 六、方法二（进阶）：迭代版，队列成对出队

递归的"下一个配对"是隐式的；迭代版把它**显式排进队列**，每次取**一对**出来检查，生成的下一批配对继续入队：

```python
class Solution:
    def isSymmetric(self, root: TreeNode | None) -> bool:
        from collections import deque
        q = deque([(root.left, root.right)])    # 第一对入场
        while q:
            l, r = q.popleft()                  # 取出一对
            if l is None and r is None:
                continue                        # 双空：这对没事，继续看下一对
            if l is None or r is None:
                return False
            if l.val != r.val:
                return False
            q.append((l.left, r.right))         # 生成的配对排队
            q.append((l.right, r.left))
        return True                             # 队列空 = 全部配对通过
```

递归版像"层层转包"，迭代版像"窗口叫号"——哪对出问题当场返回，思路完全同构。

## 📊 七、复杂度分析

- **时间 O(N)**：每个节点最多被检查一次；
- **空间 O(h)**（递归栈 = 树高；最坏链状树 O(N)）；迭代版队列最多存 O(N) 对。

实测：例 1 `True`、例 2 `False`、单节点 `True`、"3 挂外侧"的镜像树 `True`、"两个 3 挂同侧"的平移树 `False`，递归与迭代全部一致 ✅

## 🧭 要点回顾

> [!summary] 一句口诀 + 两个细节
> **口诀：双空过、单空拦、值不同拦、交叉递归。**
> 1. 三连问顺序不能换——先双空再单空，`(None, None)` 才能幸存（实测 `[1,2,2]` 误判演示）；
> 2. 起手式 `check(root, root)`：两个影子分身，一个走原样一个走镜像；
> 3. `and` 自带短路：一票否决，发现不对称立即返回。

**模板价值**：`check(l, r)` 这个"**两棵树一起递归**"的形状是树题的重要流派——把 [[二叉树的最大深度-讲解|104]] 的单树递归升级成双树对拍。改成"同侧配同侧"（`l.left ↔ r.left`）就是 **100. 相同的树**。
