# 101. 对称二叉树

## 📖 题目描述

给你一个二叉树的根节点 `root`，检查它是否**轴对称**。

> 轴对称 = 把这棵树照镜子后，和它自己**一模一样**（[[翻转二叉树|翻转]]后与自己相同）。

## 🧪 示例

> [!example] 示例 1
> **输入**：`root = [1,2,2,3,4,4,3]`
> **输出**：`true`
>
> ```text
>     1
>    / \
>   2   2
>  / \ / \
> 3  4 4  3
> ```
>
> 左右两半互为镜像 ✅

> [!example] 示例 2
> **输入**：`root = [1,2,2,null,3,null,3]`
> **输出**：`false`
>
> ```text
>     1
>    / \
>   2   2
>    \    \
>    3     3
> ```
>
> 看着像对称，其实不是：左 2 的 3 挂在**右**边，它的镜像位置是右 2 的**左**孩子——那里是空的 ❌

## 📏 数据范围

| 约束 | 值 | 暗示 |
| --- | --- | --- |
| 节点数目 | `1 ~ 1000` | 至少一个节点，不用处理空树 |
| 节点值 | `-100 <= Node.val <= 100` | 无特殊 |
| 进阶 | 递归和**迭代**两种方法 | 递归是"两棵树互相照镜子"；迭代用队列成对出队 |
