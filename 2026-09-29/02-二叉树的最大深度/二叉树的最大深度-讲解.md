# 104. 二叉树的最大深度 · 讲解

![来源](https://img.shields.io/badge/详解来源-灵茶山艾府-009688?style=flat-square) ![方法](https://img.shields.io/badge/方法-递归×2-blue?style=flat-square) ![复杂度](https://img.shields.io/badge/时间-O(N)-yellow?style=flat-square)

> [!abstract] TL;DR
> 这题是**递归思维**的第一课，同一道题给出两种视角：**自底向上**——答案从叶子往根冒泡（我的深度 = 左右报的数取大 + 1）；**自顶向下**——从根带着"我在第几层"往下走，一路刷新最高纪录。理解递归的钥匙是**数学归纳法**：只管好自己这一层，"假设孩子已经算对了"。

> [!info] 术语小卡片（后面看不懂的词，回来查这里）
> - **自底向上**：先算最小的子问题（叶子），答案像水泡一样从下往上传。
> - **自顶向下**：从根出发，带着"当前信息"（第几层）往下走，走到头之前顺便记录答案。
> - **递归边界（刹车）**：让递归停下来的最简单情况，本题是"空树返回 0"。
> - **nonlocal**：Python 关键字。内层函数想**重新赋值**外层函数的变量，必须先声明它（只读不用声明）。
> - **数学归纳法**：先证明"最小的对"，再假设"上一层对"，推出"这一层也对"。

## 🧱 一、先把上次的钩子收掉

上次留了个问题：**整棵树的深度，和左右子树的深度有什么关系？**

用"数楼层"的直觉推一下：整栋楼的高度，等于**最高的那栋侧翼 + 底层这一层**。写成公式：

$$整棵树的深度 = 1 + \max(左子树深度,\ 右子树深度)$$

空树的深度是 **0**（这是刹车，不是 1！）。

这一个公式就是**方法一**的全部——剩下只是把它翻译成代码。

## 🎯 二、方法一：自底向上（推荐先吃透）

```python
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if root is None:                      # 刹车：空树没有楼层，深度 0
            return 0
        l_depth = self.maxDepth(root.left)    # 信：左子树已经把正确的深度报上来了
        r_depth = self.maxDepth(root.right)   # 信：右子树同理
        return max(l_depth, r_depth) + 1      # 我这层：两边取大，加上我自己这层
```

> [!tip] `self` 是什么？
> 类是**图纸**，对象是照着图纸盖出来的**房子**。LeetCode 判题时先 `Solution()` 造一个对象再让它干活：`sol.maxDepth(root)`。Python 在后台把它翻译成 `maxDepth(sol, root)`——**第一个参数 `self` 接住的就是这个对象自己**。
> 所以 `self.maxDepth(...)` 读作"我自己身上的 maxDepth 工具"；TreeNode 里的 `self.val` 同理——"这个节点自己身上的值"。类方法内部调用自己的兄弟方法必须 `self.`；调用时永远不用手动传 self，Python 自动塞。

> [!tip] 递归心法：数学归纳法
> 灵神在"注"里点破的说法——"**假设递归返回的结果一定是正确的**"——本质是数学归纳法：
> 1. 最小的树（空树/叶子）答案显然对；
> 2. **假设**左右子树报上来的深度都对；
> 3. 那我取大加一，肯定也对。
>
> 你**不需要**在脑子里追着想象每一层怎么跑——只管好自己这一层的逻辑，剩下的信任递归。这是和"逐帧模拟"并列的第二个理解递归的姿势。

### 🔍 手动模拟：上次的自测树

```text
    1
   / \
  2   3
 /
4
```

答案像水泡一样**从叶子往上冒**：

| 调用 | 谁在报数 | 怎么算 | 返回 |
| --- | --- | --- | --- |
| `maxDepth(4)` | 叶子 4 | max(0, 0) + 1 | **1** |
| `maxDepth(2)` | 节点 2 | max(左 1, 右 0) + 1 | **2** |
| `maxDepth(3)` | 叶子 3 | max(0, 0) + 1 | **1** |
| `maxDepth(1)` | 根 1 | max(2, 1) + 1 | **3** ✅ |

## 🎯 三、方法二：自顶向下（换个方向走）

不让孩子报数了——**自己带着计数器下楼**，每下一层 +1，路过每个节点就刷新"最高纪录"：

```python
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        ans = 0
        def dfs(node: Optional[TreeNode], depth: int) -> None:
            if node is None:          # 刹车：走出楼外，什么都不做
                return
            depth += 1                # 我下到了新的一层
            nonlocal ans              # 声明：我要改外层的 ans（重新赋值必须声明！）
            ans = max(ans, depth)     # 刷新纪录
            dfs(node.left, depth)     # 带着层数继续下左楼
            dfs(node.right, depth)    # 下右楼

        dfs(root, 0)                  # 从根出发，出发时还没踩任何节点
        return ans
```

### 🔍 手动模拟：同一棵树

| 步 | 到达 | depth（踩到的层数） | ans 变化 |
| --- | --- | --- | --- |
| 1 | 1 | 1 | 1 |
| 2 | 2 | 2 | 2 |
| 3 | 4 | 3 | **3** 🎉 |
| 4 | （4 的左右空） | — | 3 |
| 5 | 3 | 2 | 3（没破纪录） |

### ⚠️ 语法点：为什么这次要 `nonlocal`？

接着上次的"口袋找变量"讲：内层函数**读**外层变量，直接用；但要**重新赋值**（`ans = ...`），Python 会以为你在造一个同名的**新**局部变量——必须先喊一声 `nonlocal ans`（"我说的是外套口袋里那个 ans！"）。

> [!tip] 和上一题对照
> 昨天中序遍历里 `ans.append(...)` **不用** nonlocal——因为 append 是"改列表的内容"，不是"换一个新列表"；今天 `ans = max(ans, depth)` 是把名字**指向新值**，这才触发 nonlocal。一字之差，规则不同。

## ⚖️ 四、两种视角怎么选？

| | 自底向上 | 自顶向下 |
| --- | --- | --- |
| 信息流向 | 答案**从下往上**传 | 计数**从上往下**带 |
| 像什么 | 下属汇报，领导取大 | 楼管带册子逐层登记 |
| 答案放在哪 | 根的返回值 | 外面的 `ans` 变量 |
| 适合的题 | 合并型：深度、直径、翻转…… | 路径型：路径和、路径计数…… |

本题两者都顺手。一般来说**自底向上**更常用（不用搬额外的变量），先吃透它。

## 📊 复杂度分析

- **时间 O(n)**：每个节点都被访问一次，不重复；
- **空间 O(n)**：递归栈的层数 = 树高 h（昨天说的"回程票"）；最坏情况树歪成一条链，h = n。

实测：例 1 → 3、例 2 → 2、空树 → 0、单节点 → 1、自测树 → 3、四层歪链 → 4，两种方法六组用例全部通过 ✅

## 🧭 要点回顾

> [!summary] 两句口诀 + 一个心法
> - **自底向上**：左右报数，取大加一；
> - **自顶向下**：带层下楼，逐层登记；
> - **心法（归纳法）**：写递归只管自己这一层，"假设孩子已经算对了"——不要逐帧脑内追踪。
>
> 细节两个：空树返回 **0**（刹车别写成 1）；内层函数**重新赋值**外层变量必须 `nonlocal`。
