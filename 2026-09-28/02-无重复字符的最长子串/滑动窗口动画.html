蛇身（无重复的一段） 蛇头 j 正在吃 还没爬到 过期记录（尾巴绝不倒退）
threeSum.py —— 核心三行，点亮的就是当前在跑的 
for j in range(len(s)):        # 蛇头 j 一个一个吃字符    if s[j] in dic:            # ① 查登记本：出现过吗？        i = max(dic[s[j]], i)  # ① 尾巴跳位（max 兜底，绝不倒退）    dic[s[j]] = j              # ② 登记：写入最新位置    res = max(res, j - i)      # ③ 量长度，更新最长纪录
