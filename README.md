# LeetCode 刷题笔记

按日期记录的 LeetCode 刷题笔记：每题一个文件夹，含**题目整理**与**讲解**（Python 新手向，逐行注释 + 正误对照）。

## 目录结构

```text
YYYY-MM-DD/            ← 按天分组
└── NN-题名/           ← 一题一文件夹
    ├── 题名-题目.md   ← 题面、示例、数据范围
    └── 题名-讲解.md   ← 思路比喻、关键细节、新手版逐行注释代码
```

- 讲解笔记使用 Obsidian 双链互连（在其他平台显示为普通文本）；
- 部分题目附带互动演示页面（HTML），浏览器打开即可播放；
- 题解思路参考：Krahets、灵茶山艾府等力扣题解作者，讲解文档导航处均有署名链接。
